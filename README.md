# QTify – Spotify Clone (Frontend)

QTify is a responsive Spotify-clone built with React, Material-UI, SwiperJS, and TDD. It allows users to browse music albums, top albums, and categories like jazz, pop, and more.

## Features

* **Album Browsing**: View albums with album art and details.
* **Top Albums**: See trending/top albums in a separate section.
* **Categories**: Browse songs by genres such as Jazz, Pop, etc.
* **Responsive Design**: Built with Material-UI for a modern UI.
* **Interactive UI**: Smooth swiping and navigation using SwiperJS.

## Tech Stack

* **Frontend**: React.js
* **UI Library**: Material-UI
* **Swiper**: SwiperJS for carousels and slides
* **Testing**: TDD approach with unit and integration tests

## Usage

1. Open the app in your browser.
2. Browse albums and categories.
3. Click on albums to explore songs.
4. Enjoy the smooth swiping experience.
